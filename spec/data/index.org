The Data Module contains

+ [[file:pointer/index.org][Pointer]] :: The pointer module contains the =Ptr= type, together with basic
  pointer operations (new, delete, get, set, etc.). 

+ [[file:slice/index.org][Slice]] :: A slice is the simplest way of dealing with contiguous data (arrays)
  in memory. It contains ways of accessing a specific element in the array, 

+ [[file:list/index.org][List]] :: The list module is used for dynamic, resizable lists of elements
  stored contiguously in memory, analagous to C++'s =vector= and Java's =ArrayList=.

+ [[file:maybe/index.org][Maybe]] :: The maybe module is used to represent a generic container that my
  hold a value, or may hold nothing.

+ Either :: The either module is used to represent a generic container that
  can hold one of two alternatives.

+ Pair :: The pair module is used to reprsent a generic container that holds 
  exactly two values of differing types.

+ [[file:string/index.org][String]] :: The string type represents an immutable utf-8 encoded string. The
  string module contains functions for creating and manipulating strings,
  together with some helper functions for interacting with raw sequences of
  utf-8 encoded bytes directly.
